The purpose of this application is to offer users a simple application where trips and conferences can be 
added, created, and conferences can be linked to the trips.

User Instructions:
1.Launch the application. The first screen is the login screen. Fill in
your email and a password with at least one special character and 8 characters in length.
Click 'new user'. Your login information has been saved.
2.Once logged in, notice the animation on the travel list screen. Choose from the menu to add
sample trips. 
3. On the same travel list screen, the navigation drawer offers the options to create notes, generate
a report, to share your trip, as well as a search option.
4. To see the details of one of the sample trips, tap on it. To create a new trip,
click on the add button to be taken to the trip details screen.
5. On the trip details screen, trips can be added, edited, and deleted.
The user can set an alert notifications from the menu and also can share the trip.
6. Selecting a conference from the details page or tapping the add button, takes the user to the 
conference details page. Here, a user can edit the details and save a conference.
7. A trip can not be deleted unless the associated conferences are deleted first.
